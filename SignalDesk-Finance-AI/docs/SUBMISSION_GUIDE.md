# Submission Guide

Upload the entire `SignalDesk-Finance-AI` project folder or repository link. Keep the folder structure intact.

Recommended evidence:

1. `01_home_and_input.png` — landing section and research workspace
2. `02_analysis_results.png` — sentiment, topic, figures, and executive summary
3. `03_qa_and_risks.png` — risk scan and grounded Q&A
4. `04_method_and_business_case.png` — processing workflow and real-world use case

Before submission:

- Run `npm install`, `npm run lint`, and `npm test`.
- Run the app, choose each sample, and confirm the results display.
- Do not upload `.env.local` or an API key.
- Include the GitHub repository URL if the submission form permits a link.

Suggested submission description:

> SignalDesk AI is a functional financial-news intelligence prototype that combines transparent rule-based NLP with optional generative AI. Users can paste or select finance text, receive sentiment and topic classification, extract material figures and risk language, generate a concise summary, and ask source-grounded questions. The repository includes the complete responsive application, sample data, automated checks, business-use documentation, and a deterministic fallback so the project remains fully demonstrable without a paid API key.
